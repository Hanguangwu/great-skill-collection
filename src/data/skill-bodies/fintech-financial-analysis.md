# 财报分析 Skill

基于肖星教授《一本书读懂财报》和《肖星的财务思维课》的财务分析体系，帮助你从财务数据看懂企业的经营状况、行业地位和战略执行。

## 核心财务分析框架

企业的所有经济活动可以抽象为**一个从现金到现金的周而复始的循环**。在这个循环中，企业只做三件事：
- **经营活动**：采购→生产→销售→回款
- **投资活动**：购买厂房设备、对外投资、并购
- **融资活动**：股权融资、债务融资

分析一家企业，需要从这三个维度出发，结合五大业务模块（销售、采购、生产、薪酬、投融资），层层深入。

## 一、三大财务报表分析

### 1.1 资产负债表（资产负债表——企业的单反相机）

**核心恒等式**：资产 = 负债 + 股东权益

**左边（资产）**：钱被拿去做什么了
- 流动资产（按变现速度排列）：货币资金 > 应收账款 > 预付账款 > 存货
- 非流动资产：长期投资、固定资产、无形资产、商誉

**右边（负债 + 股东权益）**：钱是从哪儿来的
- 负债：短期借款、应付账款、预收账款、应付职工薪酬、应交税费、长期借款、应付债券
- 股东权益：股本、资本公积、盈余公积、未分配利润

**分析要点**：
1. **资产结构**：重资产 vs 轻资产？固定资产占比高意味着固定成本高、经营杠杆大
2. **负债结构**：流动负债 vs 非流动负债？短期偿债压力如何？
3. **股东权益**：内部留存（未分配利润+盈余公积）vs 外部投入（股本+资本公积）
4. **关键比率**：
   - 流动比率 = 流动资产 / 流动负债（短期偿债能力）
   - 资产负债率 = 总负债 / 总资产（长期偿债能力）
   - 应收账款占比 = 应收账款 / 总资产

**注意**：资产负债表是**时点概念**，只反映制表那一刻的状况，就像给企业拍了一张照片。

### 1.2 利润表（利润表——企业的摄像机）

**核心逻辑**：收入 - 所有成本费用 = 净利润

**利润表结构**：
- 营业收入 - 营业成本 = **毛利**
- 毛利 - 营业税金及附加 - 销售费用 - 管理费用 - 财务费用 - 资产减值损失 + 公允价值变动收益 + 投资收益 = **营业利润**
- 营业利润 + 营业外收入 - 营业外支出 + 补贴收入 = **利润总额**
- 利润总额 - 所得税 = **净利润**

**关键分析**：
1. **毛利率** = (营业收入 - 营业成本) / 营业收入 —— 反映行业竞争程度和产品定价能力
2. **三大费用率** = 销售费用率、管理费用率、财务费用率
3. **营业利润 vs 净利润**：营业利润是可持续的，营业外收入不可持续
4. **注意**：有收入 ≠ 收到现金，有费用 ≠ 付出现金

**区分"可持续"与"不可持续"盈利**：
- 可持续：营业利润（主营业务）
- 不可持续：营业外收入、补贴收入、公允价值变动收益

**重要陷阱**：毛利率提升可能不是因为业绩好，而是因为产品积压（固定成本被摊到更多产品上，但只卖出了一部分）。

### 1.3 现金流量表（现金流量表——企业的真实脉搏）

**三大现金流**：
1. **经营活动现金流**：企业日常经营产生的现金流入/流出（最重要！）
2. **投资活动现金流**：购买/出售固定资产、投资/收回投资
3. **融资活动现金流**：借款/还款、吸收投资/分红

**分析要点**：
1. 经营活动现金流是企业的"造血能力"——最重要的现金流来源
2. 长期来看，经营活动现金流必须为正，否则企业无法持续
3. **利润与现金流的差异**：
   - 利润好、现金流差 → 可能是应收账款太多或存货积压
   - 现金流好、利润差 → 可能是预收账款多、折旧大、一次性支出多

### 1.4 三张报表的关系

- 资产负债表（时点） ↔ 利润表（时段）：未分配利润将两张表连接起来
- 利润表 ↔ 现金流量表：利润 ≠ 现金流，差异源于权责发生制
- **分析企业必须三张表一起看**

## 二、五大业务循环的财务分析

### 2.1 销售业务分析

**收款方式**（直接影响财务报表）：
| 收款方式 | 财务表现 |
|---------|---------|
| 一手交钱一手交货（现销） | 货币资金↑ |
| 先付款后发货（预收） | 预收账款↑（负债） |
| 先发货后付款（赊销） | 应收账款↑（资产） |
| 分期付款 | 长期应收款↑ |

**分析指标**：
- **应收账款周转天数** = 365 / (营业收入 / 平均应收账款)
- **应收账款占比** = 应收账款 / 总资产
- **坏账计提比例**：公司自主权大，可能被用来操纵利润

**应收账款背后的秘密**：
1. 应收账款回收周期→反映销售业务的组织效率
2. 应收账款→可评估客户价值（欠款多、账龄长的大客户是否值得维持？）
3. 保理业务：将应收账款卖给银行盘活资金
4. **坏账操纵利润**：先多提坏账降低利润，再转回坏账增加利润——常见于换总经理、国企转让、避免连续亏损

**其他应收款**：一个"垃圾桶"——可能隐藏关联方资金占用、小金库、违规投资

### 2.2 采购业务分析

**付款方式**（直接影响财务报表）：
| 付款方式 | 财务表现 |
|---------|---------|
| 一手交钱一手交货 | 货币资金↓，存货↑ |
| 先收货后付款（赊购） | 应付账款↑（负债），存货↑ |
| 先付款后收货（预付） | 预付账款↑（资产）|

**供应商谈判能力分析**（从财务数据倒推）：
- **预付款多** → 供应商强势（上游供不应求或供应商规模大）
- **应付款多** → 企业强势（上游竞争激烈、供应商规模小）
- **预付款和应付款都少** → 势均力敌

### 2.3 生产成本分析

**成本分类**：
- **变动成本**：随产量增加而增加（原材料、计件工资）
- **固定成本**：不随产量变化（设备折旧、固定工资）

**核心洞察**：
- 只扩大产量不扩大销量 → 毛利率可能"虚增"（固定成本被摊薄，但积压在库存中）
- 这在高固定成本的重资产行业尤为突出
- **分析毛利率时必须同时看存货变化**

**存货分析**：
- **存货周转率** = 营业成本 / 平均存货
- **存货跌价准备**：同坏账一样可能被用来操纵利润

### 2.4 薪酬与人力分析

**薪酬记录**：应付职工薪酬反映企业欠员工的工资
- 应付职工薪酬↑ → 可能拖欠工资
- 应付职工薪酬↓ → 可能预先支付

**人均效率** = 营业收入 / 员工人数

**股权激励**：期权、限制性股票等——绑定员工与公司利益

### 2.5 投融资分析

**投资活动**：
- 固定资产投资：重资产化 vs 轻资产化（租赁 vs 购买）
- 股权投资：成本法 vs 权益法
- 并购：购买法，产生商誉

**融资决策**：
- 优先顺序：自有资金 > 债务融资 > 股权融资
- 债务融资成本：利息（税前抵扣）
- 股权融资成本：分红（税后支付），成本更高

**固定资产关键概念**：
- 折旧：直线法 vs 加速折旧法
- 折旧年限的选择→影响当期利润
- 固定资产减值：一旦计提不能转回（与存货/应收账款不同）

**无形资产**：
- 自研技术支出 → 通常记入管理费用（不是无形资产！）
- 外购技术 → 可以记入无形资产
- 商誉：并购溢价，每年需做减值测试

## 三、行业与战略分析（从财务角度看）

### 3.1 Porter's Five Forces（五力图）财务体现

| 五种力量 | 影响的主要财务指标 |
|---------|------------------|
| 现有公司间竞争 | 毛利率（竞争越激烈，毛利率越低） |
| 新进入者威胁 | 毛利率、固定资产投入 |
| 替代产品威胁 | 收入增长率、毛利率趋势 |
| 购买方谈判能力 | 应收账款账期、毛利率 |
| 供应方谈判能力 | 应付账款/预付账款比例、毛利率 |

**行业对比案例**（书中数据）：
- 钢铁行业（竞争激烈）：毛利率 ~14%
- 酿酒行业（竞争缓和）：毛利率 ~50%（茅台91%）
- 软件 vs 家电零售：软件毛利率高但应收账款多，家电零售毛利率低但周转快

### 3.2 竞争战略的财务表现

**两大战略**：
1. **成本领先战略**（薄利多销）：
   - 财务表现：低毛利率 + 高周转率 = **效率制胜**
   - 典型：联想（毛利率13%，周转率2次/年）
   
2. **差异化战略**（厚利少销）：
   - 财务表现：高毛利率 + 低周转率 = **效益制胜**
   - 典型：苹果（毛利率40%，周转率0.9次/年）

**分析框架**：
- 总回报 = 效益 × 效率 = 毛利率 × 周转率
- 战略失败信号：两个指标都低（既没效益也没效率）

## 四、财务操纵识别（常见红旗信号）

### 4.1 利润操纵手法

1. **坏账操纵**：先多提坏账→第二年转回→"制造"利润增长
   - 红旗信号：连续两年亏损后第三年突然盈利
   - 红旗信号：利润波动异常平滑

2. **存货跌价准备操纵**：原理同坏账

3. **其他应收款异常**：
   - 大额其他应收款→可能有关联方资金占用
   - 红旗信号：其他应收款占比异常高

4. **虚增资产**：
   - 历史成本原则：只有花了的钱才能记在账上
   - 虚增资产=虚增利润

5. **利用折旧政策**：
   - 延长折旧年限→减少当期费用→增加利润
   - 缩短折旧年限→增加当期费用→减少利润

### 4.2 现金流量表红旗

- 净利润增长但经营活动现金流持续为负
- 应收账款增速远高于收入增速
- 存货增速远高于收入增速

## 五、分析框架总结

**完整分析一家企业的步骤**：

1. **看资产负债表**：了解企业家底
   - 资产结构（轻/重资产）
   - 负债水平（偿债风险）
   - 股东权益（积累能力）

2. **看利润表**：了解盈利能力
   - 毛利率（行业竞争、定价能力）
   - 费用率（管理效率）
   - 利润质量（可持续性）

3. **看现金流量表**：了解"真实"状况
   - 经营现金流是否为正？
   - 利润与现金流的差异？
   - 现金流来源是否健康？

4. **看效率**：周转率分析
   - 应收账款周转率
   - 存货周转率
   - 总资产周转率

5. **看行业与战略**：用财务数据验证
   - 行业竞争格局（从毛利率推断）
   - 企业战略定位（效益 vs 效率）
   - 战略执行效果（两个指标是否匹配）

6. **识别风险信号**：
   - 利润操纵嫌疑
   - 现金流恶化
   - 资产质量下降

## 六、关键财务术语表

| 中文 | 英文 | 含义 |
|------|------|------|
| 资产 | Assets | 企业拥有或控制的、能带来经济利益的资源 |
| 负债 | Liabilities | 企业需要偿还的债务 |
| 股东权益 | Shareholder's Equity | 资产减去负债后的剩余（净资产） |
| 毛利率 | Gross Margin | (收入-成本)/收入，反映产品盈利空间 |
| 周转率 | Turnover | 资产在一定时期内的"转动"次数，反映效率 |
| 折旧 | Depreciation | 固定资产价值随使用而减少的量 |
| 应收账款 | Accounts Receivable | 已经发货但未收到的货款 |
| 应付账款 | Accounts Payable | 已经收货但未支付的货款 |
| 预收账款 | Deposit Received | 已收款但未发货（负债） |
| 预付账款 | Prepaid Accounts | 已付款但未收货（资产） |
| 营业利润 | Operating Profit | 主营业务产生的利润（可持续） |
| 净利润 | Net Profit | 最终可分配的利润 |
| 经营活动现金流 | Operating Cash Flow | 日常经营产生的现金净流量 |
| 公允价值 | Fair Value | 资产当前的市场价格 |
| 历史成本 | Historical Cost | 资产购买时支付的价格 |
